AlarmDecoder Web API

Read-only JSON endpoints. The webUI IP/CIDR ACL applies to every request.

Current state

GET /api/state?partition=0

Returns a live partition snapshot and active zone alerts.
Activity history

GET /api/history?limit=64&partition=1

Returns newest-first events retained during the current boot session. The partition filter is optional.
